# Databrick-by-Databrick | KPI Trust Lab

## Purpose
This purpose of this project is to demonstrate how an organization can establish confidence in their data using governed metric definitions. We created a fictional company with multiple departments, each of which use reasonable yet conflicting definitions for Revenue, Active Customers, and Conversion Rate. We show how this company can replace ambiguous labels with governed definitions using the Unity Catalog metric views, and demonstrate the impact of this approach by comparing dashboard and Genie answers before and after governance.

##Data Source
The data used in this project comprise of six tables: customers, subscriptions, invoices, product usage, leads and opportunities. The organizations, people, transactions, and values used in this dataset were generated HOW and entirely fictional. The dataset seeks to represent the types of people, transactions, and values a business might encounter.
